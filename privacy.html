Política de privacidad

Última actualización: septiembre de 2026.

Uso de la aplicación

Esta aplicación OAuth es de uso personal y se utiliza exclusivamente para permitir que el propietario de la cuenta conecte rclone con su propia cuenta de Google Drive.

Datos de Google

La aplicación puede solicitar acceso a los archivos y metadatos de Google Drive necesarios para que rclone pueda listar, descargar, subir, copiar, mover, renombrar y eliminar archivos cuando el usuario lo solicita.

Almacenamiento de datos

El sitio web no almacena archivos de Google Drive ni recopila información personal. Las credenciales de autorización utilizadas por rclone se almacenan localmente en el dispositivo del usuario.

Compartición de información

Los datos obtenidos mediante las APIs de Google no se venden ni se comparten con terceros. Se utilizan únicamente para proporcionar la funcionalidad solicitada por el propietario de la cuenta mediante rclone.

Uso de las APIs de Google

El uso de información recibida de las APIs de Google se realizará de acuerdo con la Google API Services User Data Policy, incluidos sus requisitos de Limited Use.

Revocación del acceso

El usuario puede revocar en cualquier momento el acceso de la aplicación desde la configuración de seguridad de su cuenta de Google.
